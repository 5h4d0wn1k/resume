## Why this repo

One profile, several formats. Hiring teams, recruiters, and portfolio visitors
often need a specific version of a CV — a focused cybersecurity resume, a
founder-track resume, or a general-purpose one. This repository keeps every
version versioned in one place so links stay stable and reviewers always get
the latest copy.
